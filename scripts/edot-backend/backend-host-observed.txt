Separate stock Fleet-style agent:
  Unit: elastic-agent.service  (/usr/lib/systemd/system/elastic-agent.service)
  Uses: Environment BEAT_CONFIG_OPTS=-c /etc/elastic-agent/elastic-agent.yml
        ExecStart=/usr/bin/elastic-agent run --environment systemd $BEAT_CONFIG_OPTS

This RPM layout does not use --path.config in the unit; it passes a single file via BEAT_CONFIG_OPTS.
The EDOT gateway is therefore configured by edot-gateway.service, not by retargeting elastic-agent.service
to /etc/edot unless you intentionally merge roles (usually avoid: keep gateway on edot-gateway).
